# ศึกจานเผ็ด (Spice Showdown)

เกมเลือกอาหารเผ็ดแบบตัวต่อตัว สำหรับเล่นกับเพื่อนตอนนำเสนองาน เลือกจานโปรดจากสองจานบนจอ จานที่ไม่เลือกถูกแทนด้วยจานใหม่ ผู้ชนะอยู่ต่อ ทำไปจนเมนูหมด แล้วโชว์จานสุดท้ายพร้อมสถิติว่า **ทุกคนเลือกจานไหนเป็นจานสุดท้าย**

เป็นเว็บ static (HTML, CSS, JavaScript ล้วน) ใช้ GitHub Pages ได้เลย ไม่ต้องมีเซิร์ฟเวอร์ ทุกข้อความเป็นภาษาไทย ตั้งชื่อเกม ข้อความแนะนำ และวิธีเล่นได้เองจากหน้าผู้จัด

## มี 2 หน้า

| หน้า | ใช้ทำอะไร |
| --- | --- |
| `index.html` | หน้าผู้เล่น เล่นเกม ดูสถิติรวม |
| `admin.html` | หน้าผู้จัด แก้เมนู รูป ชื่อเกม วิธีเล่น แล้วกด **บันทึกและเผยแพร่** ขึ้น GitHub ตรง ๆ |

หน้าผู้เล่นไม่มีลิงก์ไปหน้าผู้จัด ถ้าจะเข้าให้พิมพ์ `/admin.html` ต่อท้ายที่อยู่เว็บ

## เริ่มต้นใช้งาน

1. ขึ้นเว็บด้วย GitHub Pages และสร้าง token ตาม [docs/GITHUB.th.md](docs/GITHUB.th.md)
2. เปิดหน้าผู้จัด เชื่อมต่อ GitHub แล้วแก้เมนู กด **บันทึกและเผยแพร่**
3. (ไม่บังคับแต่แนะนำ) เปิดสถิติรวมของทุกคนตาม [docs/STATS.th.md](docs/STATS.th.md) ใช้ Google Sheet ฟรี ประมาณ 5 นาที

## ข้อมูลอยู่ที่ไหน

| อะไร | อยู่ที่ | แก้อย่างไร |
| --- | --- | --- |
| เมนู ชื่อเกม วิธีเล่น | `data/menu.json` ใน repo | หน้าผู้จัด (commit ให้อัตโนมัติ) |
| รูปอาหาร | โฟลเดอร์ `images/` ใน repo | หน้าผู้จัด |
| สถิติของทุกคน | Google Sheet ของคุณ | ดู docs/STATS.th.md (ไม่ตั้งค่าก็เล่นได้ แต่สถิติจะเป็นรายเครื่อง) |

## รูปแบบ menu.json

```json
{
  "version": "v1",
  "title": "ศึกจานเผ็ด",
  "tagline": "ข้อความแนะนำใต้ชื่อเกม",
  "howTo": ["ข้อ 1", "ข้อ 2", "ข้อ 3"],
  "shuffle": true,
  "dishes": [
    { "id": "tomyum", "name": "ต้มยำกุ้ง", "heat": 3, "art": "tomyum" },
    { "id": "mala", "name": "หม่าล่าหม้อไฟ", "heat": 5, "img": "images/mala.jpg" }
  ]
}
```

- `heat` 1 ถึง 5 เมนูมีได้ 3 ถึง 16 จาน `howTo` มีได้สูงสุด 6 ข้อ
- `img` เป็น path ในโฟลเดอร์ `images/` หรือที่อยู่ `https://` ถ้าไม่มีรูป ระบบวาดภาพให้ (`art`: `tomyum`, `somtam`, `krapao`, `mala`, `tteok`, `buldak`, `vindaloo`, `nashville`)
- `shuffle: false` คือใช้ลำดับตามรายการ สองจานแรกเจอกันก่อน

## ทดลองในเครื่อง

```bash
cd spice-showdown
python3 -m http.server 8000
```

เปิด `http://localhost:8000/` และ `http://localhost:8000/admin.html` (เปิดไฟล์ตรง ๆ จะใช้เมนูตัวอย่างที่ฝังไว้)

## โครงสร้างโปรเจกต์

```
index.html        หน้าผู้เล่น
admin.html        หน้าผู้จัด
config.js         ที่ใส่ URL สถิติรวม (statsUrl)
css/              สไตล์ (base, player, admin)
js/common.js      ตัวช่วยร่วม รูปวาดตัวอย่าง
js/stats.js       ส่งผลเกมและอ่านสถิติรวม (ลองใหม่เอง มี outbox ตอนเน็ตหลุด)
js/effects.js     เอฟเฟกต์ประกาย กระดาษสี
js/player.js      ตรรกะเกม
js/admin.js       แก้เมนู และเผยแพร่ขึ้น GitHub ผ่าน API
apps-script/      Code.gs ตัวเก็บสถิติสำหรับ Google Apps Script
docs/             คู่มือ GITHUB.th.md และ STATS.th.md
data/menu.json    เมนูที่เผยแพร่
```

## ความปลอดภัยและข้อจำกัด

- token GitHub เก็บในเบราว์เซอร์ของผู้จัด เขียนได้เฉพาะ repo ที่เลือก และหมดอายุตามที่ตั้ง
- สถิติรวมออกแบบสำหรับห้องเรียนหรืองานนำเสนอ (ราว 150 เกมต่อนาที) URL ของสคริปต์เป็นสาธารณะ เหมาะกับเกมสนุก ๆ ไม่ใช่โหวตที่ต้องแม่นยำสูง
- ฟอนต์ (Mitr, Prompt) โหลดจาก Google Fonts ถ้าออฟไลน์จะใช้ฟอนต์ระบบแทน
