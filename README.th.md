# Spice Showdown (ภาษาไทย)

เกมเลือกอาหารเผ็ดแบบหนึ่งต่อหนึ่ง สำหรับใช้ตอนนำเสนองาน เลือกอาหารจากสองการ์ด อาหารที่ไม่ได้เลือกจะถูกแทนด้วยเมนูใหม่ ผู้ชนะอยู่ต่อ ทำไปจนเมนูหมด แล้วจะขึ้นอาหารที่เลือกสุดท้าย พร้อมกราฟว่าอาหารไหนถูกเลือกมากสุด

เป็นเว็บ static (HTML, CSS, JavaScript ล้วน) ไม่ต้องติดตั้งอะไร ไม่มีเซิร์ฟเวอร์ ใช้กับ GitHub Pages ได้เลย

## มี 2 หน้า

- `index.html` หน้าผู้เล่น เล่นเกมจากเมนูที่เผยแพร่แล้ว
- `admin.html` หน้า admin ใช้เพิ่ม/ลบอาหาร ตั้งระดับความเผ็ด อัปโหลดรูป แล้ว export เป็น `menu.json` (ตั้ง PIN ได้)

หน้าผู้เล่นไม่มีลิงก์ไปหน้า admin ถ้าจะเข้า ให้พิมพ์ `/admin.html` ต่อท้ายที่อยู่เว็บ

## วิธีขึ้นเว็บด้วย GitHub Pages

1. สร้าง repository แล้ว push ไฟล์ทั้งหมดขึ้นสาขา `main`
2. ไปที่ **Settings > Pages**
3. ตรง **Build and deployment** เลือก **Deploy from a branch** เลือกสาขา `main` และโฟลเดอร์ `/ (root)` แล้วกด Save
4. รอประมาณ 1 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/` ส่วนหน้า admin คือ `.../admin.html`

## วิธีเปลี่ยนเมนู (สำหรับ admin)

1. เปิด `admin.html` เพิ่มอาหาร ตั้งความเผ็ด อัปโหลดรูป แก้ชื่อเกมและข้อความแนะนำ
2. กด **Preview draft as a player** เพื่อลองเล่นด้วยเมนูที่ยังไม่เผยแพร่
3. กด **Download menu.json**
4. เอาไฟล์ที่ได้ไปแทน `data/menu.json` ใน repo แล้ว commit และ push
5. รอ GitHub Pages อัปเดตประมาณ 1 นาที ผู้เล่นจะเห็นเมนูใหม่

ฉบับร่างเก็บไว้ในเบราว์เซอร์ที่ใช้แก้ ปิดหน้าแล้วกลับมาทำต่อได้ ปุ่ม **Import menu.json** ใช้โหลดไฟล์เดิมกลับมาแก้

## ทดลองในเครื่อง

หน้าเล่นโหลด `data/menu.json` ด้วย `fetch` จึงต้องเปิดผ่านเซิร์ฟเวอร์ในเครื่อง ไม่ใช่ดับเบิลคลิกไฟล์

```bash
cd spice-showdown
python3 -m http.server 8000
```

แล้วเปิด `http://localhost:8000/` และ `http://localhost:8000/admin.html` ถ้าเปิดไฟล์ตรง ๆ เกมจะใช้เมนูตัวอย่างที่ฝังไว้แทน

## ข้อจำกัดที่ควรรู้

- **ไม่มีเซิร์ฟเวอร์** หน้า admin เปลี่ยนเมนูจริงบนเว็บเองไม่ได้ เมนูจริงเปลี่ยนเมื่อ commit `data/menu.json` เท่านั้น
- **PIN เป็นแค่ตัวกันคนผ่านมา** ตรวจในเบราว์เซอร์เทียบกับค่า hash ที่เก็บใน `menu.json` ใครก็อ่านไฟล์เว็บได้ ความปลอดภัยจริงคือใครมีสิทธิ์ push เข้า repo
- **สถิติเก็บแยกตามเครื่อง** แท็บ "This device" นับเฉพาะเกมที่เล่นในเบราว์เซอร์นั้น ยังไม่มีสถิติรวมทุกคน ถ้าต้องการต้องต่อระบบหลังบ้านเพิ่ม เช่น Google Apps Script หรือ Firebase
- รูปถูกย่อเหลือ 720 px ในเบราว์เซอร์ และถูกฝังลงใน `menu.json` ตอน export เมนู 16 รูปอาจใหญ่ราว 1-2 MB
- ฟอนต์โหลดจาก Google Fonts ถ้าออฟไลน์จะใช้ฟอนต์ระบบแทน

รายละเอียดรูปแบบไฟล์ `menu.json` และโครงสร้างโปรเจกต์ดูใน [README.md](README.md)
