# เผยแพร่เมนูขึ้น GitHub จากหน้าผู้จัด

หน้า `admin.html` กด **บันทึกและเผยแพร่** แล้วระบบจะ commit `data/menu.json` และรูปลง repo ให้เอง จากนั้น GitHub Pages อัปเดตเว็บภายใน 1 ถึง 2 นาที ไม่ต้องดาวน์โหลดหรืออัปโหลดไฟล์เอง

## ขึ้นเว็บครั้งแรก

1. สมัคร GitHub แล้วสร้าง repository ใหม่ (Public) เช่น `spice-showdown`
2. กด **Add file > Upload files** ลากไฟล์ในโฟลเดอร์โปรเจกต์ทั้งหมดเข้าไป (รวม `.nojekyll`) แล้ว **Commit changes** (หรือใช้ `git push` ตามปกติ)
3. ไปที่ **Settings > Pages** ตรง Build and deployment เลือก **Deploy from a branch** เลือกสาขา `main` โฟลเดอร์ `/ (root)` แล้ว Save
4. รอประมาณ 1 นาที ได้ลิงก์
   - หน้าผู้เล่น `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`
   - หน้าผู้จัด `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/admin.html`

## สร้าง token (ครั้งเดียว)

token คือกุญแจให้หน้าผู้จัดเขียนลง repo ของคุณเท่านั้น คนไม่มี token เปิดหน้าผู้จัดได้แต่เผยแพร่ไม่ได้

1. เปิด <https://github.com/settings/personal-access-tokens/new>
2. **Token name:** `spice-showdown` **Expiration:** 30 ถึง 90 วัน
3. **Repository access:** Only select repositories แล้วเลือก repo ของเกมนี้เท่านั้น
4. **Permissions > Repository permissions > Contents:** เลือก **Read and write**
5. กด **Generate token** แล้วคัดลอกข้อความที่ขึ้นต้น `github_pat_` (GitHub แสดงครั้งเดียว)

## ใช้งาน

1. เปิดหน้าผู้จัด ช่อง Repo จะเติมให้เอง (ถ้าไม่ตรงให้พิมพ์ `ชื่อผู้ใช้/ชื่อ-repo`) วาง token กด **เชื่อมต่อ**
2. เพิ่ม ลบ เรียงเมนู ตั้งความเผ็ด ใส่รูป แก้ชื่อเกม ข้อความแนะนำ และวิธีเล่น (หนึ่งบรรทัดต่อหนึ่งข้อ สูงสุด 6 ข้อ)
3. กด **บันทึกและเผยแพร่** แถบสถานะจะวิ่งตามขั้นตอน แล้วขึ้น "กำลังรอ GitHub Pages" จนเว็บจริงเห็นเมนูใหม่ ปิดหน้าได้ ไม่เสียงาน
4. ผู้เล่นรีเฟรชแล้วเห็นเมนูใหม่

ระบบทำให้ปลอดภัยดังนี้
- ทุกครั้งที่บันทึกจะ commit เดียวที่มีทั้งเมนูและรูป ถ้าคนอื่นแก้เมนูบน GitHub ไปก่อน จะเตือนให้เลือก "โหลดเวอร์ชันล่าสุด" หรือ "เขียนทับด้วยของฉัน"
- เน็ตหลุดหรือ token ใช้ไม่ได้ ที่แก้ไว้ยังอยู่ในหน้า (เก็บในเบราว์เซอร์) ไม่หาย
- รูปที่ไม่ได้ใช้แล้ว (ชื่อ `images/dish-...`) ถูกลบออกจาก repo ให้ ไฟล์อื่นของคุณไม่ถูกแตะ
- ย้อนกลับได้เสมอจากประวัติ commit ใน GitHub

## ข้อควรรู้

- token ถูกเก็บในเบราว์เซอร์เครื่องที่ใช้ ถ้าเป็นเครื่องส่วนกลาง เอาติ๊ก "จำการเชื่อมต่อ" ออก หรือกด "ตัดการเชื่อมต่อ" เมื่อเสร็จ ถ้า token รั่ว ให้ลบที่ GitHub Settings แล้วสร้างใหม่
- token หมดอายุตามที่ตั้ง เมื่อหมดหน้าผู้จัดจะแจ้งให้สร้างใหม่
- ถ้าไม่อยากใช้ token: กด **ดาวน์โหลด menu.json** แล้วอัปโหลดทับ `data/menu.json` ใน GitHub เอง
- สถิติของทุกคนต้องตั้ง Google Sheet เพิ่ม ดู [STATS.th.md](STATS.th.md)

## แก้ปัญหา

| อาการ | วิธีแก้ |
| --- | --- |
| "GitHub ไม่รับ token นี้" | token ผิดหรือหมดอายุ สร้างใหม่ |
| "token นี้ไม่มีสิทธิ์เขียน" | ตั้ง Contents เป็น Read and write และเลือก repo ถูกตัว |
| "ไม่พบ repo" | ตรวจชื่อ `ชื่อผู้ใช้/ชื่อ-repo` และว่า token เลือก repo นี้ไว้ |
| เมนูใหม่ยังไม่ขึ้น | รอ 1 ถึง 2 นาทีแล้วรีเฟรช ถ้ายังไม่ขึ้นดูแท็บ Actions ของ repo ว่า Pages build เสร็จหรือยัง |
| ไม่ได้ใช้ GitHub Pages จากสาขา main | ระบบใช้สาขาเริ่มต้นของ repo โดยอัตโนมัติ |
