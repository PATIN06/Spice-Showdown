# เปิดสถิติรวมของทุกคน (Google Apps Script + Google Sheet)

ทำครั้งเดียว ประมาณ 5 นาที ฟรี หลังจากนั้นทุกคนที่เล่นจบเกมจะถูกนับอัตโนมัติ และหน้าผล (แท็บ "ทุกคน") จะโชว์ว่าแต่ละจานถูกเลือกเป็น **จานสุดท้าย** กี่ครั้งและกี่ % หน้าผู้จัดก็เห็นตารางเดียวกันแบบสด

เมนูกับรูปยังอยู่บน GitHub ส่วนนี้เก็บแค่ตัวเลขสถิติ ถ้าไม่ตั้งค่า เกมก็เล่นได้ปกติ แต่จะมีสถิติแค่ในเครื่องของแต่ละคน

## 1. สร้าง Google Sheet

เข้า <https://sheets.google.com> กด **Blank spreadsheet** ตั้งชื่ออะไรก็ได้ เช่น `ศึกจานเผ็ด สถิติ`

## 2. วางโค้ด

1. ใน Sheet เมนู **Extensions > Apps Script**
2. ลบโค้ดเดิมใน `Code.gs` ให้หมด แล้ววางเนื้อหาทั้งไฟล์จาก `apps-script/Code.gs`
3. กด **Save**

## 3. รัน setup ครั้งแรก

1. เลือกฟังก์ชัน **setup** ที่แถบด้านบน แล้วกด **Run**
2. Google จะขอสิทธิ์: กด **Review permissions** เลือกบัญชีของคุณ ถ้าขึ้นว่า "Google hasn't verified this app" กด **Advanced** แล้ว **Go to ... (unsafe)** แล้ว **Allow** (สคริปต์เป็นของคุณเอง แตะแค่ Sheet นี้)
3. เมื่อขึ้น Execution completed จะมีแท็บ Stats, Settings, Log เพิ่มใน Sheet

## 4. Deploy เป็น Web app

1. มุมขวาบน **Deploy > New deployment** กดไอคอนเฟืองข้าง "Select type" เลือก **Web app**
2. ตั้ง **Execute as: Me** และ **Who has access: Anyone**
3. กด **Deploy** แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

## 5. ใส่ URL ในเว็บ

แก้ไฟล์ `config.js` ใน repo

```js
window.SS_CONFIG = {
  statsUrl: 'https://script.google.com/macros/s/xxxxxxxx/exec'
};
```

แล้ว commit และ push (แก้ผ่านหน้าเว็บ GitHub ได้: เปิดไฟล์ > ไอคอนดินสอ > Commit changes) รอประมาณ 1 นาที เล่นเกมจบ 1 รอบ ถ้าแท็บ "ทุกคน" ขึ้นกราฟ แปลว่าใช้งานได้

## การใช้งาน

- จบเกมแล้วหน้าผลเปิดแท็บ "ทุกคน" ให้เลย: แท่งยาวสุดคือจานที่คนเลือกเป็นจานสุดท้ายมากที่สุด
- หน้าเริ่มเกมขึ้น "มีคนเล่นแล้ว N เกม"
- ข้อมูลดิบดูได้ในแท็บ Stats และ Log ของ Sheet (ส่งออกเป็น Excel ได้)
- **เริ่มนับใหม่:** ใน Apps Script เลือกฟังก์ชัน **resetStats** แล้วกด Run
- เปลี่ยนชื่อจานในเมนูได้ สถิติจะอัปเดตชื่อให้เอง (นับตาม id ของจาน) จานที่ลบออกจากเมนูจะไม่โชว์ในกราฟ

## ถ้าแก้โค้ดสคริปต์ทีหลัง

ต้อง Deploy ใหม่ ไม่งั้น URL เดิมยังรันโค้ดเก่า: **Deploy > Manage deployments > ไอคอนดินสอ > Version: New version > Deploy** (URL เดิมไม่เปลี่ยน)

## แก้ปัญหา

| อาการ | วิธีแก้ |
| --- | --- |
| แท็บ "ทุกคน" ขึ้น "โหลดสถิติรวมไม่ได้" | เช็ก `statsUrl` ว่าลงท้าย `/exec` และ Who has access เป็น **Anyone** ลอง Deploy ใหม่ |
| ขึ้นว่ายังไม่ได้รัน setup | ทำขั้นตอนที่ 3 |
| เน็ตหลุดตอนจบเกม | ผลเก็บไว้ในเครื่องและส่งซ้ำเองเมื่อออนไลน์ ไม่นับซ้ำ |
| ตัวเลขช้ากว่าความจริงเล็กน้อย | ระบบแคชสถิติ 15 วินาที |

## ข้อจำกัด

- ออกแบบสำหรับห้องเรียนและงานนำเสนอ รับได้ราว 150 เกมต่อนาที เกินนั้นระบบจะให้ส่งซ้ำอัตโนมัติ
- URL ของสคริปต์เป็นสาธารณะ ใครมี URL ก็ส่งผลปลอมได้ในทางทฤษฎี (ระบบตรวจว่าลำดับการเลือกเป็นไปได้จริงเท่านั้น) เหมาะกับเกมสนุก ๆ ไม่ใช่การโหวตที่ต้องแม่นยำสูง
- เก็บสถิติได้สูงสุด 300 จานต่างกัน (กันข้อมูลขยะ) เกินนั้นจะไม่เพิ่มแถวใหม่
