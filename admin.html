จัดการเมนู

เพิ่มเมนู ตั้งความเผ็ด ใส่รูป ตั้งชื่อเกมและวิธีเล่นได้ตามใจ เมื่อเสร็จให้เชื่อมต่อ GitHub แล้วกด บันทึกและเผยแพร่ ระบบจะอัปเดตเว็บให้เอง

มีคนแก้เมนูบน GitHub ไปก่อนแล้ว

เมนูบน GitHub ไม่ตรงกับเวอร์ชันที่คุณเริ่มแก้ เลือกว่าจะโหลดเวอร์ชันล่าสุด (การแก้ไขตรงนี้จะหายไป) หรือเขียนทับด้วยของคุณ

รายการเมนู

    ทุกคนชอบจานไหนที่สุด

    สด

        เพิ่มเมนู

        ระดับความเผ็ด
        รูปอาหาร (ไม่ใส่ก็ได้)

        รูปจะถูกย่อเหลือ 720 px ในเครื่องคุณก่อนอัปโหลด เมนูได้สูงสุด 16 จาน

        ตั้งค่าเกม

        ถ้าปิดสลับ สองจานแรกในรายการจะเจอกันก่อน แล้วจานถัดไปตามลำดับ

        เผยแพร่ขึ้น GitHub

        เชื่อมต่อครั้งเดียว หลังจากนั้นกดปุ่มเดียวเพื่อบันทึกเมนูและรูปลง repo ของคุณ แล้ว GitHub Pages จะอัปเดตเว็บเอง

        วิธีสร้าง token (ทำครั้งเดียว)
        1. เปิด github.com/settings/personal-access-tokens/new (ต้องล็อกอิน GitHub)
        2. ตั้งชื่อ token เช่น spice-showdown และเลือกวันหมดอายุ (แนะนำ 30 ถึง 90 วัน)
        3. ตรง Repository access เลือก Only select repositories แล้วเลือก repo ของเกมนี้เท่านั้น
        4. ตรง Permissions > Repository permissions ตั้ง Contents เป็น Read and write
        5. กด Generate token แล้วคัดลอกข้อความที่ขึ้นต้นด้วย github_pat_ มาวางในช่องด้านบน (GitHub จะแสดงให้ดูครั้งเดียว)

        token นี้เขียนได้เฉพาะ repo ที่คุณเลือก และถูกเก็บไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น ถ้าใช้คอมพิวเตอร์ส่วนกลาง ให้เอาติ๊ก "จำไว้" ออก หรือกด "ตัดการเชื่อมต่อ" เมื่อเสร็จ

        ฉบับร่างในเครื่องนี้

        ที่แก้ไว้จะถูกเก็บในเบราว์เซอร์ ปิดหน้าแล้วกลับมาทำต่อได้

        ดูตัวอย่างฉบับร่างแบบผู้เล่น
